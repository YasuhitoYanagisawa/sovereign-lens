Sovereign Lens — システムアーキテクチャ

政府系ファンドの日本株保有を自律的に収集・採点・理由調査し、利用者の資産に合わせた配分案を作るマルチエージェント（ADK + Gemini on Cloud Run）

利用者

ブラウザ（PC/スマホ）
金額・リスク・期間を入力
プランを確認・承認し、発注は自分の証券口座で
Google Cloud（asia-northeast1）

Cloud Run：FastAPI

Web UI（静的）REST APISSEストリーム
入力検証（Pydantic）・レート制限（IP毎 8回/10分）・即時試算 API（LLM不要）

ガバナンス層（ADK Plugin）

・プロンプトインジェクション検知
・ツール許可リスト／1実行30回までの予算
・全ツール呼び出しを構造化監査ログに記録
・発注・認証情報の要求をブロック
・人による承認が前提（発注機能なし）

オーケストレーター（LlmAgent）

Gemini（Vertex AI）
収集→採点→理由調査→配分→審査を自分で判断して進め、審査で指摘があれば除外銘柄を調整して作り直す

理由調査エージェント

Gemini + Google検索グラウンディング
事実と推測を分け、出典を付けて要約

審査エージェント（独立）

集中リスク・情報の鮮度・断定表現を審査し、承認可／修正推奨を返す
