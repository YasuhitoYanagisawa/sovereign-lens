## はじめに

ノルウェー政府年金基金（NBIM）、サウジアラビアの公共投資基金（PIF）、シンガポールのGIC。こうした政府系ファンド（SWF）は、数十年単位の長期目線で日本株に投資しています。

その足跡は公開されています。EDINETの大量保有報告書や、NBIMの全保有銘柄データです。ただし、個人投資家が日々追いかけるのは現実的ではありません。

**Sovereign Lens** は、この「プロの足跡」をAIエージェントが自律的に集めて分析し、利用者の資産サイズに合わせた投資戦略のたたき台にするシステムです。

## 解決したい課題

- **情報が分散している。** 大量保有報告書はXBRLやPDF、NBIMのデータは英語のJSONです。
- **「誰が持っているか」だけでは役に立たない。** 個人が知りたいのは次のようなことです。
  - いくらで買ったのか
  - いつから持っているのか
  - なぜ買ったのか
  - 自分の資金で何株買えばいいのか
- **真似ると偏る。** 例えばPIFの日本株は、任天堂・カプコン・ネクソン・コーエーテクモ・スクウェア・エニックスなど、ゲーム株に集中しています。

## データから見えたこと

データを集める過程で、次のことがわかりました。

- **PIFのゲーム株は2026年1月に移管されていた。** カプコン・ネクソン・コーエーテクモ・東映・スクウェア・エニックスの株を、グループ会社のAyar First Investmentへ無対価で移管していました。同時にバンダイナムコの5.05%も新たに報告されています。
- **推定取得単価を計算できる。** 大量保有報告書の「取得資金合計 ÷ 保有株数」を株式分割で調整すると求められます。例えばPIFのネクソンは約3,005円、任天堂は約6,025円です。
- **NBIMの数字には注意が必要。** ノルウェー銀行の取得資金には貸株などの回転が含まれるため、単価の推定には使えません。システムでは「推定不可」と明示しています。

## アーキテクチャ

![](https://raw.githubusercontent.com/yasuhitoyanagisawa/sovereign-lens/main/docs/architecture.png)

- **Cloud Run**：FastAPIで、Web UI、REST、SSEストリームを提供
- **Agent Development Kit（ADK）**：オーケストレーター、理由調査エージェント（Google検索グラウンディング）、独立審査エージェント
- **Gemini（Vertex AI）**
- **Cloud Trace / Cloud Logging / Secret Manager**

### 自律性：エージェントが自分で進める

利用者が金額・リスク・期間を入れると、オーケストレーターが次の手順を自分で判断して進めます。

1. Sovereign Conviction Score で候補を採点
2. 上位銘柄の資料（保有者・取得コスト・保有期間）を確認
3. 「なぜそのファンドが買ったか」をGoogle検索で調査（事実と推測を分けて出典付き）
4. 決定論的エンジンで配分を計算
5. 独立審査エージェントが集中リスクなどを指摘。必要なら除外銘柄を変えて作り直す

### 制御：LLMに数字を作らせない

配分の数値はすべて Python のツールが計算します。

- 1銘柄・1業種の上限、現金比率の下限、リスク別の銘柄規模フィルタはコードで強制しています。
- 金額3パターン×リスク3パターン×期間2パターンの全組み合わせで、ガードレールが守られることをテストで確認しています。

### ガバナンス：ADK Plugin

`BasePlugin` を継承した `GovernancePlugin` で、すべてのツール呼び出しを通しています。

- 入力のプロンプトインジェクション検知と、発注・認証情報の要求のブロック
- ツールの許可リストと、1回の実行あたり30回までの呼び出し上限
- 構造化監査ログ（Cloud Logging）

さらに、発注機能そのものを持たせていません。プランは人が確認・承認し、自分の証券口座で実行する設計です。

### テストのしやすさ

ADKの `BaseLlm` を継承した「台本どおりに動く偽LLM」を作りました。これを使い、Runner → Plugin → ツール → セッション状態までの一連の流れを、ネットワークなしでテストしています。許可リストにないツール呼び出しがブロックされることも、このテストで確認しています。

## おわりに

政府系ファンドの長期目線を、すべての個人投資家に。Sovereign Lens は、そのための「レンズ」です。
